Convolutional Networks (CNNs)

Dense layers flatten 2D image matrices into 1D vectors → destroys all spatial topology!

Solution: Parameter Sharing. Slide small K × K kernel over input image instead of full matrix multiplication.

Feature Map Output Size:
Output = ⌊ (W - K + 2P) / S ⌋ + 1
↑ W = input ↑ K = filter ↑ P = padding ↑ S = stride
★ CORE INSIGHT: Pooling layers have NO learnable parameters — they purely downsample dimensionality!

ReLU: f(x) = max(0, x) zeroes negative signals → gradient flows at rate 1 without vanishing!

Local-First Optimistic Sync Pipeline

  • • Non-blocking UI: Key input mutates local memory synchronously — zero wait for cloud round-trips.
  • • Debounced Batching: Rapid keystrokes merge into a single 500ms cloud commit to conserve network quota.
  • • Per-User Namespaces: Local storage keys isolated by user UID (aiNoteData_${uid}).
sync-pipeline.js 0ms perceived latency 
// Optimistic state dispatch
window.onNotesStateChanged = (data) => {
  saveLocalSnapshot(currentUser.uid, data); // 0ms instant
  debounce(() => firestore.save(currentUser.uid, data), 500);
};

So... WHY THIS?

EDITOR’S NOTE

Couldn't find a note taking app that looked the way I wanted. Everything felt either way too corporate or packed with features I'd never use. I grew up using stuff like Photoshop and VS Code, so I ended up stealing that whole vibe and turning it into a place for notes instead.

I never sat down with a big plan for this. I just wanted to see what a notes app would look like if I built it my way. One feature turned into another, a few late nights disappeared, and it slowly became the website your looking at now.

“Honestly, I didn't have anything better to do.”

- anam razzaque

Most note-taking apps get the job done. I just wanted one that looked and felt a little different without making everything more complicated.
