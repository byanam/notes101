Convolutional Networks (CNNs)

Dense layers flatten 2D image matrices into 1D vectors → destroys spatial geometry & explodes parameters!

Solution: Parameter Sharing. Slide a small K × K kernel across input space to extract local features.

Feature Map Output Dimension:
Output = ⌊ (W - K + 2P) / S ⌋ + 1
W = input size K = filter size P = padding S = stride

Key Takeaway: Pooling layers have no learnable weights — they strictly downsample spatial resolution to prevent overfitting.

Local-First Optimistic Sync Pipeline

  • • Non-blocking UI: Key input mutates local memory synchronously — zero wait for remote cloud round-trips.
  • • Debounced Batching: Rapid keystrokes coalesce into a single 500ms cloud commit to conserve network quota.
  • • Per-User Namespaces: Local storage keys are cleanly isolated by authenticated UID.
  • • Offline Resilient: Editing never stutters during network dropouts; state automatically syncs when online.

EDITOR’S NOTE

Couldn't find a note taking app that looked the way I wanted. Everything felt either way too corporate or packed with features I'd never use. I grew up using stuff like Photoshop and VS Code, so I ended up stealing that whole vibe and turning it into a place for notes instead.

I never sat down with a big plan for this. I just wanted to see what a notes app would look like if I built it my way. One feature turned into another, a few late nights disappeared, and it slowly became the website your looking at now.

“Honestly, I didn't have anything better to do.”

- anam razzaque

Most note-taking apps get the job done. I just wanted one that looked and felt a little different without making everything more complicated.
